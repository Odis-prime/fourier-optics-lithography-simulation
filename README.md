## Fourier Optics and Lithography Simulation

### Theory, Numerical Methods, and Applications in Semiconductor Manufacturing

This project explores the fundamental principles of Fourier optics and their applications in optical lithography.

The study combines theoretical derivations, numerical simulations, and scientific visualization using Python and Jupyter Notebooks.

**Main topics:**
- Electromagnetic wave propagation
- Fresnel and Fraunhofer diffraction
- Fourier transforms and optical imaging
- Numerical simulations using FFT
- Resolution limits in semiconductor lithography
